# Build the distribution inside its measurement copy

## Context

An XS distribution needs an object compiled for the selected interpreter.
Tests can load generated Perl modules whose contents differ from the source.

## Decision

Configure and build a private project tree before measuring its tests.
Use the selected interpreter with MakeMaker or `Build.PL`.
Keep the resulting products in the reference tree for mutant jobs.
Replace byte-identical copies directly.
When a build transforms a source, run its incremental command after placement and compare the generated bytes.
An unchanged product yields `NoVerdict` with its path and the reason `build-copy-not-updated`.
`mutation exec` reports the unchanged product and selected source and exits before launching the requested command.
In-place measurement identifies stale files and gives the command to rebuild them.

## Alternatives

Reusing an object from another distribution can load a different implementation.
Rebuilding for every mutant repeats work even for identical copies.

## Consequences

A failed build ends the run with the command and its diagnostic.
Build products stay inside the workspace.

## Confirmation

Exercise a compiled XS function, both build commands, an unchanged generated file, an old in-place product, and a configuration failure.
